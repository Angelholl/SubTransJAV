# 上下文 sidecar 模板（v1.2.2 C1）

## 用法

把本文件内容复制一份，放到**与待翻译 srt 同目录**，文件名与 srt 同名、
后缀改为 `.context.md`。例如：

```
某影片.srt
某影片.context.md   <- 本模板改名的文件
```

- 两个小节标题（`【剧情摘要】`、`【误听怀疑】`）必须原样保留，各写一份；
- 误听怀疑词条**按片填写**：只写本片 ASR 转写中确实出现过疑似误听的词，
  不要把其他片的词条抄过来（词条按"当前批次源文命中"才注入，但表本身
  应保持每片最小化）；
- 以 `#` 开头的行视为注释，不参与注入；
- 不需要某个小节时，保留标题、内容留空即可；
- 不想要 sidecar 时直接删除该文件，或在 `config/user_settings.json` 中
  设 `"context_sidecar": false` 全局禁用；
- 已知边界：sidecar 文件内容不参与断点续跑指纹——修改 sidecar 后请勿
  `--resume` 复用旧阶段产物，必要时用 `--force` 重跑。

## 模板正文（复制以下内容）

```markdown
【剧情摘要】
（用 2-5 行中性文字概述本片背景：人物关系、场景、时间线。
只写确实在片中出现的信息，供消解指代与歧义；此处内容不会改写原文。）

【误听怀疑】
# 每行一条，格式：疑似词 => 疑似正解（半角 => ，两侧留空格）
# 仅当上下文无法按字面义解读时模型才会按疑似义翻译；可两可时照字面译。
ペソ => おへそ
```

## 示例（中性占位）

```markdown
【剧情摘要】
本片为单人室内访谈场景，对话围绕日常爱好展开。
出场人物两名：访读者与受访姐妹，全程同一房间。

【误听怀疑】
ペソ => おへそ
マズミ => 真面目に
```

## 注入与留痕口径（供理解，无需填写）

- 剧情摘要块在 A/B 两阶段提示词均注入，引导语为固定措辞：
  「以下为剧情背景参考，仅用于消解歧义；与单句字面义和术语表冲突时，
  以句子本身和术语表为准；不得改写原文中没有的信息。」
- 误听怀疑词条仅当当前批次源文包含疑似词时才注入，措辞为固定句式：
  「该词在 ASR 转写中曾出现误听（疑似词→疑为疑似正解）。仅当上下文无法
  按字面义解读、且存在语义更合理的解读时方可按疑似义翻译；可两可时
  一律照字面译。」
- 终稿生成后，质量报告新增【误听疑似改写】小节：源文命中任一疑似词的
  条目全部列入（命中即列的保守审计口径，不代表已按疑似义改写），供
  人工复核译义方向。
