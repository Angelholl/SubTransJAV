# 行动层可离线重建与标陈旧清单

D11 契约④⑤ 行动层重翻执行器（`subtransjav/refine/action_retranslate.py`）
在**不重跑 v2 管线**的前提下改写 `{stem}_final_cn.srt` 并刷新导读快照。
本文逐件登记：哪些产物可离线重建、哪些只能标陈旧（需管线态信息、离线
不可得，重跑管线即自然重算）。

## 逐件清单

| 产物 | 处置 | 依据 |
| --- | --- | --- |
| `{stem}_final_cn.srt` | **可离线重建** | 执行器用 `build_srt` 整文件重建：选中块替换 text，恒等式硬断言（条目数一致、逐块 timing 全等、非选中块 text 逐字节全等）保证只动选中块；写前断言失败即抛异常不落盘 |
| `{stem}_质量报告导读.json` | **可离线重建**（快照刷新） | 执行器同 dict 刷新：`generated_at` 更新为当前同源时间串（`%Y-%m-%d %H:%M:%S`，与管线同款）、顶层加 `retranslated_at`、`items[].current_text` 按新 final 经 `resolve_final_block`（精确 index 匹配）重定位、companions 六件存在性经 `write_guide_json` 重算；`conclusions`/`sections`/`extras` 原样保留。**保真度注记**：结论区/统计区数字是旧终稿的快照，不随重翻重算，仅 `current_text` 与存在性表反映新终稿 |
| `{stem}_质量报告.txt` | **标陈旧** | 报告由管线态 `merge_stats`（闸门0/预合并/清洗统计）与终稿对比渲染，离线缺管线态输入不可重算；重跑管线即自然重算 |
| `{stem}_分歧复核.csv` | **标陈旧** | 需管线态双引擎分歧探测（pass_disagreement 对阶段A/阶段B 双通道产物的比对），离线不可得 |
| `{stem}_术语冲突观察.csv` | **标陈旧** | 需管线态校验告警与词库冲突扫描链路，离线不可得 |
| `{stem}_重翻记录.json` | 执行器自有台账（不重建、不标陈旧） | 累积追加的审计件：`index/timing/category/old_text/new_text/model_used/outcome/reason/ts/source_partial`；`old_text` 即回滚依据（apply 不另做备份文件）。新一轮管线跑写前清旧（`_remove_stale_risk_reports` 第四件），并在入口打印告警 |

## 用法示例

```bash
# 1) dry-run（缺省）：只打印计划（index/类别/timing/现译前 50 字/源文可得性），零写入
subtransjav-refine --action-retranslate "输出目录/ep01_质量报告导读.json"

# 2) 选中条目 + 真正落盘
subtransjav-refine --action-retranslate "输出目录/ep01_质量报告导读.json" \
    --entries "3,7,12-15" --apply

# 3) 提供原始日文 SRT 恢复完整源文（按 timing 精确对齐；未命中退化为导读摘录）
subtransjav-refine --action-retranslate "..." --entries "3" \
    --action-source "ep01.ja.srt" --apply

# 4) 换模型重翻（缺省用槽 B / 阶段B 模型）
subtransjav-refine --action-retranslate "..." --apply --action-model "other-model"
```

退出码沿用 cli 口径：`0`=全部应用成功；`1`=全败（含清单缺失、终稿不存在）；
`2`=--entries 非法格式；`3`=部分降级（部分应用部分失败）。

## 5 条小样对比工作流（换模型 A/B）

```bash
# 基准腿：槽 B 默认模型，只跑前 5 条
subtransjav-refine --action-retranslate "..." --action-sample 5 --apply

# 对照腿：换 --action-model 再跑同样的前 5 条（dry-run 不调用 LLM，对比需 --apply；
# 两腿各自生成台账记录，old_text 同源，便于逐条 diff new_text 与 model_used）
subtransjav-refine --action-retranslate "..." --action-sample 5 \
    --action-model "对照模型名" --apply
```

两腿跑完后，在 `{stem}_重翻记录.json` 中按 `ts`/`model_used` 分组，对同一
`index` 的 `new_text` 做人工 diff 即可对比模型表现。

## 偏离契约的显式记录

1. **源文恢复经 `--action-source` 按 timing 对齐**：契约只给出
   `--action-source` 参数名，未约定对齐键；本实现选 timing 精确匹配首个
   命中（与终稿块定位同键），未命中/未传参退化为导读 `source_excerpt`
   并在台账标 `source_partial=true`。
2. **重算四件中三件归类"标陈旧"的依据**：质量报告 txt / 分歧复核 csv /
   术语冲突观察 csv 分别依赖管线态 `merge_stats`、双引擎分歧探测、校验
   告警链路，均属离线不可得信息；执行器只打印陈旧清单（含本文档指引），
   不做任何伪重算。
3. **退出码 2**：`--entries` 非法格式沿 argparse 惯例报错退出 2，其余
   执行失败归 1。
4. **apply 不做备份文件**：回滚依据为台账 `old_text`；`--force` 管线重跑
   时台账随其余成品一起进 `_backup_existing_outputs` 八件备份表。
5. **quality_report=False 的管线运行不重写不清理两 CSV**：`{stem}_分歧复核.csv`
   与 `{stem}_术语冲突观察.csv` 在 quality_report=False 的运行中不重写不清理
   （上一轮件留存，重跑 quality_report=True 即自然重算）——清理表若收编会在
   该类运行里无备份删除上一轮成品伴生件，违背备份语义，故按 D11 残余观察①
   选文档标注留痕（不扩 `_remove_stale_risk_reports` 清理表）。
